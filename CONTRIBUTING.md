# Contributing

DeepSeek Harness is designed to be deeply customizable. Packages in this repository are an official showcase, not a mandate: the ecosystem works because people build their own plugins and share what they learn.

Ways to help:

- Report issues and discuss ideas in GitHub Discussions.
- Publish a plugin and tag its repository with the `dsh-plugin` topic.
- Answer questions and write about how you use the harness.

Into the unknown.
